# Cadastro de Tecidos

Este é o meu primeiro projeto no GitHub

## Sobre o projeto

A ideia surgiu de um problema que observei na empresa onde trabalho: a necessidade de registrar e organizar os tipos de tecidos jeans coletados, controlando a quantidade de sacos de cada tipo (cada saco pesa 20kg) e o peso total coletado.

Como estou começando a estudar programação, decidi usar essa necessidade real como motivação para aprender Python na prática, e futuramente evoluir o projeto com um banco de dados (SQL) para persistir as informações.

## Funcionalidades atuais

- Cadastro de tipo de tecido e quantidade de sacos coletados
- Cadastro contínuo (repete até o usuário decidir encerrar)
- Resumo agregado por tipo de tecido (soma de sacos por tipo)

## Próximos passos

- Calcular o peso total por tipo de tecido (sacos × 20kg)
- Persistir os dados em um banco de dados (SQLite)
- Consultas com SQL para relatórios de coleta
